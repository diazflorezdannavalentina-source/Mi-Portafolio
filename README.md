# Portafolio Profesional — Danna Valentina Díaz Flórez

Portafolio web profesional de una sola página (One Page), desarrollado con HTML5 semántico, CSS3 moderno y JavaScript vanilla, con diseño retrofuturista oscuro con acentos neón violeta y cian.

---

## 🚀 Tecnologías

- **HTML5 Semántico**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- **CSS3 Moderno**: Variables CSS, Flexbox, CSS Grid y Media Queries.
- **JavaScript Vanilla**: Menú responsive y enlace activo al hacer scroll.
- **Google Fonts**: *Inter* y *Fira Code*.

---

## 💻 Cómo Abrir y Ejecutar en Visual Studio Code

1. Abre **Visual Studio Code**.
2. Ve a `File` > `Open Folder...` y selecciona la carpeta `portfolio-danna`.
3. Instala la extensión **Live Server** (Ritwick Dey) si no la tienes.
4. Haz clic derecho sobre `index.html` y elige **Open with Live Server**.
5. Se abrirá en tu navegador en `http://127.0.0.1:5500`.

## 🌿 Estructura de Ramas (Git Flow)

- `main`: Rama de producción (código publicado).
- `develop`: Rama de integración.
- `feature/header`: Barra de navegación y menú móvil.
- `feature/about`: Sección sobre mí.
- `feature/skills`: Sección de habilidades.
- `feature/projects`: Proyectos con repositorios reales.
- `feature/contact`: Sección de contacto y footer.
